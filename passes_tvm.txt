** DEFAULT **
DispatchSampling: Dispatches sampling operators to their backend implementations,
DispatchSortScan: Dispatches sort and scan operators to their backend implementations,
LegalizeOps: Rewrites high-level operators into legal Relax or TensorIR implementations,
ToNonDataflow: Converts dataflow blocks into ordinary Relax blocks,
RemovePurityChecking: Removes purity checks from Relax functions,
CallTIRRewrite: Rewrites call_tir calls into the form expected by the VM,
LowerAllocTensor: Lowers tensor allocation operations,
LowerRuntimeBuiltin: Lowers runtime builtin operations,
ComputePrimValue: Computes primitive values that can be evaluated at compile time,
VMShapeLower: Lowers shape operations for the Relax virtual machine,
AttachGlobalSymbol: Attaches global symbols required by code generation,

** DEPENDENCY **
ConvertToDataflow: Converts eligible Relax bindings into dataflow blocks for passes that operate on dataflow,
ExpandMatmulOfSum: Expands matrix multiplication over sums for matmul rewrite optimizations,
AnnotateTIROpPattern: Annotates TensorIR operator patterns used by FuseOps and downstream fusion,

** OPTIMIZATION **
ToMixedPrecision: Converts eligible operations to mixed precision while preserving the configured accumulation dtype,
AdjustMatmulOrder: Reorders matrix multiplication expressions to expose more efficient computation patterns,
CanonicalizeBindings: Canonicalizes Relax variable bindings,
FoldBatchnormToConv2D: Folds inference batch normalization into a preceding Conv2D,
FastMathTransform: Rewrites operations to use faster mathematical approximations where supported,
EliminateCommonSubexpr: Eliminates repeated equivalent expressions,
FuseTransposeMatmul: Reorders transpose and matrix multiplication operations to improve execution,
InlinePrivateFunctions: Inlines eligible private Relax functions,
CombineParallelMatmul: Combines compatible parallel matrix multiplication operations,
ReorderPermuteDimsAfterConcat: Reorders permute dimensions after concatenation where valid,
ReorderTakeAfterMatmul: Reorders take operations after matrix multiplication where valid,
RemoveRedundantReshape: Removes reshape operations that do not change tensor shape,
FoldConstant: Evaluates constant expressions at compile time,
FuseOps: Fuses compatible Relax operators,
DataflowUseInplaceCalls: Rewrites eligible dataflow operations to use in-place calls,
FuseTIR: Fuses Relax operators and their TensorIR implementations,
SpecializePrimFuncBasedOnCallSite: Specializes primitive functions using call-site information,
RewriteDataflowReshape: Rewrites reshape operations within dataflow blocks,
TopologicalSort: Sorts bindings in topological dependency order,
RemoveUnusedOutputs: Removes unused function outputs,
RemoveUnusedParameters: Removes unused function parameters,
DeadCodeElimination: Removes computations whose results are unused,
LazyTransformParams: Defers eligible parameter transformations,
StaticPlanBlockMemory: Statically plans memory for Relax blocks,
KillAfterLastUse: Releases intermediate values after their final use,
